Features

Covers the playbooks a SOC actually runs

Every rule in the skill was written after a real failure on a FortiSOAR appliance, and most of them are enforced by the bundled validator.

Alert triage & response

Playbooks that trigger on alert create or update, set severity, assign owners and close false positives.

IOC enrichment

Look up IPs, domains, URLs and file hashes across threat-intel connectors and record the verdicts.

Phishing analysis

Parse reported emails, extract and enrich indicators, and decide whether to quarantine.

FortiSIEM & FortiAnalyzer

Threat-hunting queries with correct event attribute names, built from a reference of 7,000+ FortiSIEM fields.

Response actions

Block, isolate and disable steps, with client approval links through manual input before anything runs.

PDF & HTML reports

Generate incident reports inside FortiSOAR and attach them to the record automatically.

How it works

From idea to import in three steps

No hand-editing JSON. Describe the logic the way you would explain it to a colleague.

Describe it

Tell Claude what should trigger the playbook, what to check and what to do.

Claude builds & validates

The skill writes the full export and runs the static validator to catch problems FortiSOAR would reject.

Import into FortiSOAR

Import the JSON file in FortiSOAR, add your connector configs, and run it.

You

Install

Add it to Claude in under a minute

Pick the Claude app you use.

Run these inside Claude Code:

/plugin marketplace add git-Jimit/fortisoar-playbook-builder
/plugin install fortisoar-playbook-builder@fortisoar-skills

Then just ask for a FortiSOAR playbook. The skill loads automatically.

Install with the open skills CLI (needs Node.js):

npx skills add git-Jimit/fortisoar-playbook-builder

It asks which agent to install into, such as Claude Code. The skill then loads automatically.

  1. Download the latest release and unzip it.
  2. Zip the skills/fortisoar-playbook-builder folder on its own.
  3. In Claude, open Customize → Skills → Upload skill and choose that zip.

Copy the skill into your personal Claude skills folder:

git clone https://github.com/git-Jimit/fortisoar-playbook-builder.git
cp -r fortisoar-playbook-builder/skills/fortisoar-playbook-builder ~/.claude/skills/

Validate any existing export on its own:

python3 skills/fortisoar-playbook-builder/scripts/validate_playbook.py my_playbook.json

FAQ

Questions

Is FortiSOAR Playbook Builder free?

Yes. It is open source under the MIT License. You need your own Claude account to use it.

Does the skill connect to my FortiSOAR instance?

No. Claude writes a JSON export file, and you import it into FortiSOAR yourself. The bundled scripts make no network calls.

Which Claude apps does it work in?

Claude Code as a plugin, and Claude.ai or the Claude desktop app by uploading the skill folder.

Can it review a playbook I already have?

Yes. Give it an existing FortiSOAR playbook export and it can review, debug, extend or adapt it for another client or tenant.

Is it made by Fortinet?

No. It is an independent community project, not affiliated with or endorsed by Fortinet.
